================================================================================
     دليل التثبيت والتشغيل السحابي لنظام ترياق لإدارة الصيدليات (Teryaq Cloud)
================================================================================

هذه النسخة مجهزة بالكامل للعمل بالربط السحابي المركزي (Supabase / Render / PostgreSQL)،
وتدعم ربط الفروع المتعددة في قاعدة بيانات موحدة مع ميزة العمل دون إنترنت (Offline Sync).

--------------------------------------------------------------------------------
1. محتويات المجلد (الملفات الأساسية)
--------------------------------------------------------------------------------
- PharmacySystem.exe : البرنامج التنفيذي الكامل (يعمل بنقرة واحدة).
- .env               : ملف الإعدادات السحابية لوضع رابط السحابة DATABASE_URL.
- schema_postgres.sql: مخطط وهيكل جداول قاعدة البيانات السحابية (Supabase).
- schema.sql         : مخطط قاعدة البيانات المحلية للطوارئ وانقطاع الإنترنت.
- فحص_الاتصال_السحابي.bat: أداة فحص واختبار سريعة للتأكد من نجاح الاتصال بالسحابة.
- تشغيل_النظام.bat   : سكربت تشغيل ينشئ اختصار سطح المكتب ويفتح البرنامج.
- push.bat           : سكربت رفع التحديثات الجديدة إلى GitHub بنقرة واحدة.
- push_to_github.py  : سكريبت الرفع الآمن إلى GitHub لتحديث استضافة Render تلقائياً.
- render.yaml & Procfile & requirements.txt : ملفات نشر الخادم السحابي على Render.
- app.ico            : أيقونة شعار ترياق الرسمية لاختصار سطح المكتب.

--------------------------------------------------------------------------------
2. خطوات الربط السحابي مع Supabase (خطوة بخطوة)
--------------------------------------------------------------------------------
أ) تجهيز قاعدة البيانات:
   1. افتح حسابك على موقع https://supabase.com وأنشئ مشروعاً جديداً.
   2. ادخل على SQL Editor داخل لوحة تحكم مشروع Supabase.
   3. افتح ملف "schema_postgres.sql" وانسخ كل محتواه، ثم الصقه في SQL Editor واضغط RUN.
      (سيتم إنشاء كافة الجداول، والمنتجات، والمبيعات، وأسعار الصرف بالدولار).

ب) استخراج رابط الاتصال (DATABASE_URL):
   1. من لوحة Supabase، اذهب إلى:
      Project Settings -> Database -> Connection string
   2. اختر تبويب URI وتأكد من اختيار Session أو Transaction (المنفذ 6543 أو 5432).
   3. انسخ الرابط واستبدل [YOUR-PASSWORD] بكلمة سر قاعدة بياناتك الحقيقية.
      مثال للرابط الصحيح:
      postgresql://postgres.xxx:mypassword@aws-0-eu-central-1.pooler.supabase.com:6543/postgres

ج) تفعيل الرابط في البرنامج:
   1. افتح ملف ".env" الموجود في هذا المجلد بالمفكرة (Notepad).
   2. ضع الرابط أمام خانة DATABASE_URL كالتالي:
      DATABASE_URL=postgresql://postgres.xxx:mypassword@aws-0-eu-central-1.pooler.supabase.com:6543/postgres
   3. احفظ الملف.

د) الفحص والتشغيل:
   1. اضغط مرتين على "فحص_الاتصال_السحابي.bat" للتأكد من أن السحابة جاهزة ومستجيبة.
   2. اضغط على "تشغيل_النظام.bat" أو "PharmacySystem.exe" وسيعمل النظام سحابياً فوراً!

--------------------------------------------------------------------------------
3. خطوات النشر السحابي والتحديث التلقائي على Render
--------------------------------------------------------------------------------
لكي يعمل النظام كخدمة ويب (Web Service) تعمل أونلاين 24/7 من أي متصفح أو هاتف:
1. ارفع التعديلات إلى GitHub بنقرة واحدة عبر الضغط مرتين على ملف "push.bat".
2. ادخل إلى لوحة https://dashboard.render.com وأنشئ Web Service جديدة مربوطة بمستودع GitHub.
3. الإعدادات المطلوبة في Render:
   - Build Command: pip install -r requirements.txt
   - Start Command: gunicorn app:app --bind 0.0.0.0:$PORT --workers 2 --timeout 120
4. في قسم Environment Variables داخل Render، أضف:
   - DATABASE_URL = رابط اتصال Supabase السحابي.
   - PYTHON_VERSION = 3.11.9
   - FLASK_DEBUG = false
   - SECRET_KEY = اضغط Generate لإنشاء مفتاح تشفير عشوائي.
5. اضغط Deploy وستحصل على رابط موقع رسمي ومحمي لتشغيل الصيدلية من أي مكان.

--------------------------------------------------------------------------------
4. ميزة العمل بدون إنترنت (Offline Resilience)
--------------------------------------------------------------------------------
إذا انقطع الإنترنت في أي فرع صيدلية:
- يستمر الكاشير في البيع والطباعة وإصدار الفواتير محلياً دون أي توقف.
- عند عودة الإنترنت، يقوم النظام بمزامنة كافة الحركات تلقائياً مع السحابة المركزية
  عبر نافذة المزامنة السحابية (Sync) في لوحة الإدارة.
